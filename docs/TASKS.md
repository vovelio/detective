# TASKS — последовательный план разработки для Codex

Основной принцип: **сначала проверяемый вертикальный срез игры, потом улучшение стола**. Не параллелить сильно связанные этапы без тестов. Перед каждой задачей читать соответствующий документ, показывать короткий план изменений и критерий готовности.

Retention только предложен, автоматической очистки нет. Этап8 не начат.

## Чего Codex не должен делать «по собственной инициативе»

Встраивать голос, регистрацию, одиночную игру, генератор ИИ на сайте, рейтинг игроков, группировку/resize карт, Redis, микросервисы, хранение секретных данных во frontend, автоматическую проверку вместо ручной, превращать общее голосование в индивидуальные ответы.
