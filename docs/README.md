# Detective — документация MVP

Версия документации: `1.0-draft`, 15 ноября 2026 г.  
Язык продукта и документации: русский.

## Цель

Реализовать браузерную кооперативную детективную игру в духе механики настольной серии «Элементарно!»: участники получают личные карты, решают, раскрыть или сбросить каждую, обсуждают опубликованные сведения, совместно отвечают на финальные вопросы и получают оценку.

**Критерий успеха MVP:** друзья могут без помощи разработчика сыграть **полную партию на реальном сервере**: создать комнату, подключиться, раздать карты, довести расследование до конца, ответить и увидеть результат; критических ошибок нет. Автотесты обязательны, но не заменяют эту проверку.

## Источники решений и статусы

- **Согласовано с заказчиком:** без аккаунтов; внешняя голосовая связь; одиночный режим позже; ручное подтверждение правильности ответов; правило о личных карточках; автоматическая передача хода; восстановление после обрыва/обновления; интерфейс и стол; ведущий — создатель комнаты; отдельный импорт собственной игры; успешность — реальная полная партия.
- **Технический выбор:** React + TypeScript + Vite; FastAPI; SQLAlchemy + Alembic; PostgreSQL; WebSocket; Caddy; Docker Compose; один процесс API в MVP; сервер — источник истины.
- **Операционные/форматные детали, закреплённые этим комплектом как рабочие значения по умолчанию:** схема JSON, версия пакета, модель HTTP/WS, правила хранения и восстановления, ограничения загрузки, форматы ошибок. Их можно изменять через версионирование документов, не переоткрывая уже принятые пользовательские решения.

## Приоритет при противоречиях

1. Новое явное решение пользователя;
2. `GAME_RULES.md` для игровой логики и `SCENARIO_FORMAT.md` для схемы дела;
3. `UI_SPEC.md` для UI и `ARCHITECTURE.md` для транспорта/хранения;
4. `TASKS.md` и `AGENTS.md` для организации работ.

Источники механики для проверки: [правила «Элементарно! Смерть археолога»](https://tesera.ru/images/items/1707877/Rules-elementarno-smert-arkheologa-rus.pdf), [страница издателя](https://lifestyleltd.ru/games/elementarno-1-smert-arxeologa/). Используем общие игровые принципы и оригинальные, специально созданные тексты/изображения; чужие дела и иллюстрации не включаются.

## Быстрый старт для Codex

1. Прочесть `AGENTS.md`, затем документы в порядке `TASKS.md`.
2. Сверить формат сценария с `schema/detective-case.schema.json`.
3. Делать небольшие проверяемые этапы; каждый этап заканчивать тестами и фиксировать выполненное в `TASKS.md`.
4. Не расширять MVP без отдельного решения.
