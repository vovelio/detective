# Как подготовить и загрузить своё дело

Для загрузки нужен готовый **`.detective` — ZIP-архив с `case.json` в корне**.
Это не текстовый файл с переименованным расширением и не папка, вложенная в ZIP.
Регистрация не нужна; загружает ведущий комнаты до начала партии.

## Где взять файл

Для быстрой проверки используйте готовый учебный архив
[demo-case.detective](examples/demo-case.detective). Это демонстрация формата,
не законченное релизное расследование.

Для собственного оригинального дела используйте [SCENARIO_FORMAT.md](SCENARIO_FORMAT.md)
и [JSON Schema](schema/detective-case.schema.json). Готовый
[CASE_GENERATION_PROMPT.md](CASE_GENERATION_PROMPT.md) можно передать внешней ИИ-модели
вместе с форматом и схемой. Встроенной генерации в приложении нет.

Если автор/ИИ выдал только JSON, сохраните его в UTF-8 как `case.json`. Настоящие
изображения, объявленные в `assets`, положите в папку `assets/`; без изображений
оставьте пустой массив assets и используйте текстовые блоки. Не добавляйте ссылки на
файлы, которых нет. Не копируйте коммерческие сценарии.

На macOS из папки, где лежит `case.json`:

```sh
# Текстовое дело — без изображений:
zip -X my-case.detective case.json

# Либо дело с настоящими изображениями (перечислите нужные файлы явно):
zip -X my-case.detective case.json assets/photo-01.png assets/map.webp
```

Выберите один подходящий вариант. Не используйте `zip -r` для всей рабочей папки:
архив не должен содержать каталоги, `.DS_Store`, `__MACOSX`, исходники или лишние файлы.
Для новой версии архива используйте новое имя выходного файла, чтобы старые элементы
не остались внутри существующего ZIP.

Формат версии1.0.0 проверяет структуру, ссылки, ограничения и ресурсы. Он не доказывает
единственность разгадки: автору нужна отдельная ручная редакторская проверка. Человек,
который читал case.json/разгадку при подготовке, уже может знать ответы.

## Проверка перед загрузкой

Из корня проекта при установленном Python-окружении:

```sh
PYTHONPATH=backend .venv/bin/python -m detective.scenarios /полный/путь/my-case.detective
```

Ожидается `Valid detective-case 1.0.0 package`. При отказе исправьте указанные поля или
ресурсы и заново упакуйте архив. CLI не раскрывает содержание карточек и разгадки.

Существующие пределы пакета: ZIP до20MiB, распакованное содержимое до80MiB,
не больше100 файлов, PNG/JPEG/WebP до16млн пикселей, без анимации. HTTP-импорт имеет
дополнительные технические ограничения времени/обработки; см. IMPORT_API.md.

## Загрузка через интерфейс

1. Откройте локальный сайт и создайте комнату. Создатель — ведущий.
2. В лобби нажмите **«Добавить свою игру»** и выберите `.detective`.
3. Нажмите **«Загрузить дело»**, дождитесь проверки. Не нажимайте запуск до её завершения.
4. При ошибке прочитайте причину и путь поля, исправьте архив и загрузите снова.
5. После успеха выберите загруженное дело в списке сценариев. Сам импорт не выбирает
   дело и не запускает партию автоматически.
6. Подключите второго участника и нажмите **«Начать игру»**.

Дело доступно только этой комнате. Другие комнаты не получают его через общий каталог.
Участники видят публичное название/описание; личные карты и правильные ответы остаются
закрыты по обычным игровым правилам. Архив не раздаётся участникам целиком.

## Если связь прервалась

Дело могло сохраниться, даже если ответ не пришёл. Обновите список дел в интерфейсе
или страницу. При необходимости повторно выберите тот же файл: повтор одинакового
архива безопасен и не создаёт дубликат.

Архив с тем же внутренним `case.json.id`, но другим содержимым не заменяет прежнее дело.
Для отдельной переработанной версии автор должен задать новый уникальный ID и загрузить
её в лобби. Уже запущенную партию нельзя поменять загрузкой или выбором другого дела.
При перезапуске API сохраняйте ту же PostgreSQL, `.env` и приватный каталог CASE_STORAGE_PATH.
